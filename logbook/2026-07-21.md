## 21/07/2026 - Telephony, electricity, videos... and the website

Well... it's been a little while since the last update here x)

HospitalityLab isn't dead at all, I just haven't been posting as much on GitHub lately. I've mostly been spending my time experimenting with new equipment, working on the lab and making YouTube videos.

And quite a few things have happened since the last update.

### ☎️ More telephony

The telephony side of HospitalityLab has grown quite a bit.

I've continued experimenting with **FreePBX**, SIP and IP phones, and I've also started working with **Mitel equipment**.

What started with a few simple VoIP experiments is slowly becoming a proper telephony environment, with much more to test and understand in the future.

There are still plenty of things planned around PBX systems, extensions, call routing and eventually hospitality-specific telephony.

### ⚡ A bit of electricity too

I've also started doing more things around **electrical systems**.

This part is still at an early stage, but it naturally connects with almost everything already in HospitalityLab: networking, automation, fire safety, TV infrastructure and the rest.

So... another category that will probably become unnecessarily complicated sooner or later x)

### 🎥 More YouTube, less GitHub

I've definitely been focusing more on **YouTube** lately.

I really enjoy being able to directly show equipment, connect it, test it and explain how it works.

Because of that, GitHub has been a little quieter.

I'm not abandoning it at all, but I think it makes more sense to keep GitHub mainly for code, files, configurations and technical resources instead of trying to document absolutely everything here.

### 🌐 The next big step: the website

The next major objective is now to finish the **V1 of hospitalitylabproject.com**.

The domain is online and the first landing page is already running, but I now want to turn it into the real home of HospitalityLab.

The website will make it possible to create much better articles with:

- Photos
- Equipment references
- Documentation
- Videos
- Projects
- Downloads
- Related content

Instead of having information scattered between GitHub and YouTube, the goal is to progressively connect everything together in one place.

So yes, GitHub has been a little quiet...

But the lab definitely hasn't x)

A lot more is coming.
